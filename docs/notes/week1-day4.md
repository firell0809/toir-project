# День 4. SQL: тестовые данные и запросы

## Что узнал
- `INSERT INTO` позволяет массово добавлять готовые строки в таблицы базы данных.
- Оператор `JOIN` (или `INNER JOIN`) связывает строки двух таблиц на основе общего поля (например, ID цеха).
- `GROUP BY` объединяет строки с одинаковыми значениями в группы, чтобы применять к ним подсчёты (`COUNT`, `AVG`).
- `LIMIT` жестко обрезает количество строк в выводе до указанного числа.

## Вопросы
1. **Чем LEFT JOIN отличается от обычного JOIN?**
   Обычный `JOIN` оставляет в результате только те строки, которые нашлись в обеих таблицах. `LEFT JOIN` гарантированно вернёт все строки из левой таблицы, даже если в правой таблице для них нет никаких совпадений (вместо них подставит `NULL`).
2. **Что делает оператор HAVING?**
   `HAVING` работает точно так же, как и `WHERE`, но используется исключительно для фильтрации результатов группировки `GROUP BY` (например, отсеять группы, где количество записей меньше определённого числа).
