# День 1. C#: первое приложение

## Что узнал
- `dotnet new console` создаёт проект с файлом Program.cs.
- `Console.WriteLine()` – вывод в консоль.
- `var` – неявный тип, компилятор сам определит тип переменной.
- `DateTime` – тип для работы с датами. Разница двух дат даёт тип `TimeSpan`, у которого свойство `.TotalHours` возвращает часы.
- `git checkout -b` – создать и переключить ветку.

## Вопросы
1. **Чем int отличается от long?** 
   `int` занимает в памяти 32 бита (4 байта) и вмещает числа примерно до 2 миллиардов. `long` занимает 64 бита (8 байт) и используется для огромных чисел (до 9 квинтиллионов).
2. **Что делает dotnet sln add?**
   Эта команда привязывает конкретный проект (`.csproj`) к общему файлу решения (`.sln`), чтобы компилятор видел их как единую связанную систему.
