# День 2. C#: классы и списки

## Что узнал
- Класс служит шаблоном для объектов, а объект — это конкрестный экземпляр.
- Ключевое слово `override` у метода `ToString()` позволяет определить, как объект будет автоматически печататься в консоли.
- Инициализация ` = ""` помогает избежать ошибок с неопределенными `null`-строками.
- Методы `.Where()` и `.OrderBy()` из технологии LINQ позволяют в одну строчку фильтровать и сортировать коллекции объектов.

## Вопросы
1. **Чем класс отличается от структуры?**
   Класс — это ссылочный тип данных (хранится в управляемой куче), поддерживает полноценное наследование. Структура — тип значения (хранится в стеке), используется для легковесных данных и не поддерживает наследование от других структур.
2. **Зачем нужен метод `ToString()`?**
   Это стандартный метод .NET, который есть у абсолютно любого объекта. По умолчанию он выводит просто полное имя класса, но его переопределение (`override`) даёт возможность выводить удобную текстовую информацию об объекте.
